### About the Course
This course starts from the very basics, so no prior Git or GitHub knowledge is needed. It explains the "logic" and language behind Git, then applies everything in practical, easy-to-follow examples, from your first commit to collaborating with others on GitHub.

**Key topics covered:**
- Command line crash course (Windows & macOS)
- Git installation & setup
- Git theory: Working Directory, Staging Area (Index) & Repository
- Commits, branches & merging
- Undoing changes (e.g. deleting or amending your last commit)
- Stashing, cherry-picking & rebasing
- Forks & Pull Requests
- GitHub Issues & GitHub Projects
